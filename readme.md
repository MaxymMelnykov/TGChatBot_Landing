# Лендінг бакалаврської роботи

Односторінковий вебсайт для представлення бакалаврської роботи. Створено з урахуванням сучасних вимог доступності, SEO та адаптивності.

## Стратегія гілкування
Використано **GitHub Flow**:
- Основна гілка `main`
- Розробка нових фіч у `feature/*` гілках
- Об’єднання через pull request
